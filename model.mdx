    </li>

      <div className="smb-step-title">State Prediction</div>
      <div className="smb-step-desc">Given the current patient state <em>S(t)</em> and an intervention <em>A(t)</em>, the model predicts the future state <em>S(t+1)</em> in latent space — not as text, but as a dense embedding.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Hybrid Optimization</div>
      <div className="smb-step-desc">The model combines supervised fine-tuning (anchoring to clinical outcomes) with JEPA objectives (learning dynamics), preventing training collapse.</div>
    </li>
  </ol>

  {/* ==================== EXTRACTING EMBEDDINGS ==================== */}

  <h2 className="smb-h2">Extracting Embeddings</h2>

  <p className="smb-p">
    smb-v1 is a <strong>causal</strong> model — use <strong>last-token pooling</strong> to extract the patient embedding. The final token's hidden state captures the model's full causal representation of the patient trajectory up to that point.
  </p>

  <div className="smb-callout smb-callout-info">
    <strong>Why last-token pooling?</strong> In causal (autoregressive) transformers, each token can only attend to itself and prior tokens. The last token is the only position that has attended over the entire input sequence, making it the natural summary vector. Mean pooling would dilute this with early-token states that lack full context.
  </div>

  <div className="smb-code-wrap">
    <div className="smb-code-label">python</div>
    <pre className="smb-code-block"><code>{`from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

MODEL_ID = "standardmodelbio/smb-v1-1.7b"

tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)
model = AutoModelForCausalLM.from_pretrained(
    MODEL_ID,
    trust_remote_code=True,
    device_map="auto",
)
model.eval()

# Prepare input (in practice, use smb_utils.process_ehr_info to serialize MEDS data)
text = "patient clinical data here"
inputs = tokenizer(
    text,
    return_tensors="pt",
    truncation=True,
    max_length=4096,
).to(model.device)

# Extract embedding via last-token pooling
with torch.no_grad():
    outputs = model(
        inputs.input_ids,
        attention_mask=inputs.attention_mask,
        output_hidden_states=True,
    )
    # Last layer, last token → patient embedding
    patient_embedding = outputs.hidden_states[-1][:, -1, :]  # (batch, 2048)

print(f"Embedding shape: {patient_embedding.shape}")  # (1, 2048) for smb-v1-1.7b`}</code></pre>
  </div>
