  {/* ==================== HOW IT WORKS ==================== */}

  <h3 className="smb-h3">How It Works</h3>

  <ol className="smb-steps">
    <li className="smb-step">
      <div className="smb-step-title">Modality Ingestion</div>
      <div className="smb-step-desc">Raw signals — genomics, proteomics, imaging, EHR data — pass through modality-specific encoders. Each encoder is trained to extract meaningful representations from its data type.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Fusion Layer</div>
      <div className="smb-step-desc">A specialized projector maps these encodings into a universal latent space. This creates a "fused" patient state embedding that retains both high-level semantic context and low-level biological granularity.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">State Prediction</div>
      <div className="smb-step-desc">Given the current patient state <em>S(t)</em> and an intervention <em>A(t)</em>, the model predicts the future state <em>S(t+1)</em> in latent space — not as text, but as a dense embedding.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Hybrid Optimization</div>
      <div className="smb-step-desc">The model combines supervised fine-tuning (anchoring to clinical outcomes) with JEPA objectives (learning dynamics), preventing training collapse.</div>
    </li>
  </ol>

  {/* ==================== EXTRACTING EMBEDDINGS ==================== */}

  <h2 className="smb-h2">Extracting Embeddings</h2>

  <p className="smb-p">Get patient state embeddings for downstream tasks:</p>

  <div className="smb-code-wrap">
    <div className="smb-code-label">python</div>
    <pre className="smb-code-block"><code>{`from transformers import AutoModel, AutoTokenizer
import torch

model = AutoModel.from_pretrained("standardmodelbio/smb-v1-1.7b")
tokenizer = AutoTokenizer.from_pretrained("standardmodelbio/smb-v1-1.7b")

device = "cuda" if torch.cuda.is_available() else "cpu"
model = model.to(device)
model.eval()

# Prepare input
inputs = tokenizer(
    "patient clinical data here",
    return_tensors="pt",
    padding=True,
    truncation=True
).to(device)

# Extract embeddings
with torch.no_grad():
    outputs = model(**inputs)
    embeddings = outputs.last_hidden_state

    # Pool to get single patient embedding
    patient_embedding = embeddings.mean(dim=1)  # [batch, hidden_dim]

print(f"Embedding shape: {patient_embedding.shape}")`}</code></pre>
  </div>
