  {/* ==================== ARCHITECTURE ==================== */}

  <h2 id="architecture" className="smb-h2">Architecture</h2>

  <p className="smb-p">
    GenVarFormer is a compact transformer (993K parameters) with 4 layers, 64-dimensional embeddings, and 4 attention heads. Each mutation is represented as a feature vector encoding sequence context, variant type, allele fraction, and chromosomal position. The model attends jointly over all mutations in a 16 Mbp window, learning which variants — individually or in combination — shift gene expression.
  </p>

  <p className="smb-p">
    At the patient level, per-gene mutation embeddings are mean-pooled and concatenated into a patient-level representation suitable for downstream survival modeling, subtype classification, or multimodal fusion with smb-v1.
  </p>

  <h3 className="smb-h3">How It Works</h3>

  <ol className="smb-steps">
    <li className="smb-step">
      <div className="smb-step-title">Identify Window</div>
      <div className="smb-step-desc">For a target gene, collect all somatic mutations within ±8 Mbp of the transcription start site (TSS) from the patient's VCF.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Build Per-Mutation Features</div>
      <div className="smb-step-desc">For each mutation, extract: alternative allele sequence (<code>ALT</code>), indel length (<code>ILEN</code>), variant allele fraction (<code>VAF</code>), 32 bp flanking sequences (<code>FLANK_5</code>, <code>FLANK_3</code>), and chromosomal position (<code>POS</code>).</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Encode Mutations</div>
      <div className="smb-step-desc">Pass the mutation feature matrix through GenVarFormer. The transformer attends over all mutations simultaneously to produce a 64-dim embedding per mutation.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Predict Gene Expression</div>
      <div className="smb-step-desc">A scalar prediction head outputs the expected expression change for the target gene.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Build Patient Embedding</div>
      <div className="smb-step-desc">Mean-pool mutation embeddings across all genes and concatenate to form a patient-level vector for downstream tasks.</div>
    </li>
  </ol>

    "standardmodelbio/genvarformer",
    trust_remote_code=True,
).to(device).eval()

# ----- 2. Prepare mutation features for one gene -----
# Each row = one somatic mutation within the 16 Mbp window
mutations = pd.DataFrame({
    "ALT":     ["T", "GCTA", "A"],
    "ILEN":    [0, 3, -1],
    "VAF":     [0.42, 0.15, 0.87],
    "FLANK_5": ["ACGTACGT" * 4, "TTGCAACG" * 4, "CGATCGAT" * 4],
    "FLANK_3": ["GCTAGCTA" * 4, "AATCGGCC" * 4, "TTAGCCGT" * 4],
    "POS":     [12345678, 12400000, 12800000],
})

# ----- 3. Tokenize & encode -----
tokenizer = AutoTokenizer.from_pretrained(
    "standardmodelbio/genvarformer",
    trust_remote_code=True,
)
inputs = tokenizer(mutations.to_dict("records"), return_tensors="pt").to(device)

with torch.no_grad():
    outputs = model(**inputs)

# Gene-level: scalar expression prediction
expression_pred = outputs.expression_logits      # (1,) or (n_genes,)

# Mutation-level embeddings — mean-pool for gene embedding
mutation_embeddings = outputs.last_hidden_state  # (1, n_mutations, 64)
gene_embedding = mutation_embeddings.mean(dim=1) # (1, 64)

print(f"Predicted expression delta: {expression_pred.item():.4f}")
print(f"Gene embedding shape:       {gene_embedding.shape}")
