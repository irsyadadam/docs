  {/* ==================== ARCHITECTURE ==================== */}

  <h2 id="architecture" className="smb-h2">Architecture</h2>

  <p className="smb-p">
    <strong>smb-vision-v0</strong> is built on V-JEPA2 with a ViT-L backbone (<code>standardmodelbio/smb-vision-vjepa2-vitl-384-256</code>). It processes 3D volumes as non-overlapping patch tubelets of size 16×16×16, using Rotary Position Encodings (RoPE) to model spatial relationships across the full volume. Multi-scale context is captured via DeepStack layers that aggregate features at different resolutions.
  </p>

  <p className="smb-p">
    <strong>smb-vision-v1</strong> (<code>standardmodelbio/smb-vision-v1</code>) initializes from Qwen3-VL and scales to 0.6B parameters with improved visual grounding. It shares the same input preprocessing pipeline and output embedding format as v0, making the two variants drop-in replaceable.
  </p>

  <h3 className="smb-h3">How It Works</h3>

  <ol className="smb-steps">
    <li className="smb-step">
      <div className="smb-step-title">Load & Reorient</div>
      <div className="smb-step-desc">Load the DICOM or NIfTI volume with MONAI's <code>LoadImaged</code>, then reorient axes to standard RAS orientation with <code>Orientationd</code>.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Resample</div>
      <div className="smb-step-desc">Resample voxels to isotropic spacing of 1.0 × 1.0 × 1.5 mm using <code>Spacingd</code> so every scan has a consistent physical scale.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Normalize Intensity</div>
      <div className="smb-step-desc">Apply a Hounsfield Unit window of [–1000, 1000] and scale to [0.0, 1.0] with <code>ScaleIntensityRanged</code>.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Crop & Pad</div>
      <div className="smb-step-desc">Crop to foreground with <code>CropForegroundd</code>, then pad to the target spatial size of 384 × 384 × 256 with <code>SpatialPadd</code>.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Encode</div>
      <div className="smb-step-desc">Pass the preprocessed tensor through the encoder. The model returns <code>last_hidden_state</code> of shape <code>(batch, seq_len, 1024)</code>.</div>
    </li>
  </ol>

  {/* ==================== EXTRACTING EMBEDDINGS ==================== */}

  <h2 id="embeddings" className="smb-h2">Extracting Embeddings</h2>

  <div className="smb-code-wrap">
    <div className="smb-code-label">python</div>
    <pre className="smb-code-block"><code>{`import torch
from monai.transforms import (
    Compose,
    LoadImaged,
    Orientationd,
    Spacingd,
    ScaleIntensityRanged,
    CropForegroundd,
    SpatialPadd,
)
from transformers import AutoModel

# ----- 1. Preprocessing pipeline -----
preprocess = Compose([
    LoadImaged(keys=["image"]),
    Orientationd(keys=["image"], axcodes="RAS"),
    Spacingd(keys=["image"], pixdim=(1.0, 1.0, 1.5), mode="bilinear"),
    ScaleIntensityRanged(
        keys=["image"],
        a_min=-1000, a_max=1000,
        b_min=0.0,   b_max=1.0,
        clip=True,
    ),
    CropForegroundd(keys=["image"], source_key="image"),
    SpatialPadd(keys=["image"], spatial_size=(384, 384, 256)),
])

# ----- 2. Load & preprocess a CT volume -----
data = preprocess({"image": "/path/to/ct_scan.nii.gz"})
volume = data["image"]                    # (C, H, W, D)
volume = volume.unsqueeze(0)              # (1, C, H, W, D)

# Reshape to model input: (batch, slices, channels, H, W)
volume = volume.permute(0, 4, 1, 2, 3)  # (1, 256, 1, 384, 384)

# ----- 3. Load encoder -----
device = "cuda" if torch.cuda.is_available() else "cpu"
model = AutoModel.from_pretrained(
    "standardmodelbio/smb-vision-vjepa2-vitl-384-256",
    torch_dtype=torch.float16,
    device_map="auto",
)
model.eval()

# ----- 4. Extract embeddings -----
with torch.no_grad():
    outputs = model(pixel_values=volume.to(device))
    embeddings = outputs.last_hidden_state   # (1, seq_len, 1024)

# Pool over sequence to get a single scan-level vector
scan_embedding = embeddings.mean(dim=1)     # (1, 1024)
print(f"Scan embedding shape: {scan_embedding.shape}")`}</code></pre>
