  {/* ==================== ARCHITECTURE ==================== */}

  <h2 id="architecture" className="smb-h2">Architecture</h2>

  <p className="smb-p">
    KRONOS couples two components. A <strong>GAT graph encoder</strong> operates on the STRING protein-protein interaction network: each node represents one protein, and node features are the patient's measured protein abundances from mass spectrometry (~4,800 proteins per patient). Graph attention layers propagate information across the PPI network, producing a patient-specific graph embedding that captures the topology of dysregulated protein pathways.
  </p>

  <p className="smb-p">
    This graph embedding is projected and prepended as a soft prefix to a <strong>Vicuna-7b-v1.5</strong> language model. A natural language clinical instruction is then appended, and the LLM generates the answer — either a classification label or a free-text response. The joint model is instruction-tuned on CPTAC-PROTSTRUCT, a dataset of 381K question-answer pairs derived from 1,000+ CPTAC cancer patients.
  </p>

  <h3 className="smb-h3">How It Works</h3>

  <ol className="smb-steps">
    <li className="smb-step">
      <div className="smb-step-title">Build Patient Graph</div>
      <div className="smb-step-desc">Load the STRING PPI network. For each protein node, set the node feature to the patient's measured protein abundance (log-normalized mass spectrometry intensity). Missing proteins are imputed with population means.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Encode with GAT</div>
      <div className="smb-step-desc">The graph attention encoder aggregates neighborhood information across PPI edges, producing a per-patient graph embedding that reflects the topology of protein dysregulation.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Project to Language Space</div>
      <div className="smb-step-desc">A learned linear projector maps the graph embedding into the token embedding space of Vicuna-7b, creating a soft prefix that conditions the LLM on the patient's proteomic state.</div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Answer Clinical Question</div>
      <div className="smb-step-desc">Append a natural language instruction (e.g., "What is the predicted cancer type for this patient?") and run autoregressive decoding to generate the prediction.</div>
    </li>
  </ol>

  <h2 id="embeddings" className="smb-h2">Extracting Embeddings</h2>

  <div className="smb-code-wrap">
    <div className="smb-code-label">python</div>
    <pre className="smb-code-block"><code>{`import torch
import numpy as np
from torch_geometric.data import Data
from transformers import AutoModelForCausalLM, AutoTokenizer

# ----- 1. Load model -----
device = "cuda" if torch.cuda.is_available() else "cpu"
model = AutoModelForCausalLM.from_pretrained(
    "standardmodelbio/kronos",
    trust_remote_code=True,
    torch_dtype=torch.float16,
    device_map="auto",
).eval()
tokenizer = AutoTokenizer.from_pretrained(
    "standardmodelbio/kronos",
    trust_remote_code=True,
)

# ----- 2. Build patient graph -----
# protein_abundances: float array of shape (n_proteins,) = ~4800 values
protein_abundances = np.load("/path/to/patient_proteomics.npy")  # (4800,)
node_features = torch.tensor(protein_abundances, dtype=torch.float32)

# edge_index: (2, n_edges) — STRING PPI edges pre-filtered to your protein set
edge_index = torch.load("/path/to/string_ppi_edge_index.pt")

patient_graph = Data(
    x=node_features.unsqueeze(0),  # (1, n_proteins)
    edge_index=edge_index,
).to(device)

# ----- 3. Encode clinical instruction -----
instruction = "What is the predicted cancer type for this patient?"
inputs = tokenizer(instruction, return_tensors="pt").to(device)

# ----- 4. Run inference -----
with torch.no_grad():
    outputs = model.generate(
        **inputs,
        graph_data=patient_graph,   # patient proteomic graph
        max_new_tokens=64,
        do_sample=False,
    )

answer = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(f"Prediction: {answer}")

# ----- 5. Extract patient graph embedding (for downstream use) -----
with torch.no_grad():
    graph_embedding = model.encode_graph(patient_graph)  # (1, hidden_dim)
print(f"Patient embedding shape: {graph_embedding.shape}")`}</code></pre>
