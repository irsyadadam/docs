  <div className="smb-code-wrap">

    <pre className="smb-code-block"><code>bash -c "$(curl -fsSL https://docs.standardmodel.bio/quickstart.sh)"</code></pre>

  <p className="smb-p">This script will:</p>

  <p className="smb-p">
    1. Clone the <a href="https://github.com/standardmodelbio/quickstart">quickstart repo</a> with demo.py and all dependencies.<br/>
    2. Install <a href="https://docs.astral.sh/uv/">uv</a> if not already present.<br/>
    3. Run uv sync to install the exact locked dependency set (PyTorch, transformers, smb_utils, etc.).
  </p>

  <div className="smb-callout smb-callout-info">
    GPU support is strongly recommended. smb-v1-1.7b has 1.7B parameters and requires approximately 16 GB GPU memory for inference.
  </div>

  <h2 id="manual-installation" className="smb-h2">Manual Installation</h2>

  <div className="smb-callout smb-callout-note">
    <strong>Requirements:</strong> Python 3.11+, Git, and <a href="https://docs.astral.sh/uv/">uv</a>.<br/><br/>
    The quickstart uses <a href="https://docs.astral.sh/uv/">uv</a> for dependency management. If you prefer a different tool (conda, pip, etc.), refer to pyproject.toml in the <a href="https://github.com/standardmodelbio/quickstart">quickstart repo</a> for the list of dependencies.
  </div>

  <ol className="smb-steps">
    <li className="smb-step">

cd quickstart

  <h3 id="verify-installation" className="smb-h3">Verify Your Installation</h3>

  <p className="smb-p">
    From the quickstart/ directory, verify that everything is working:
  </p>

```python
uv run python -c "
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

print(f'PyTorch version: {torch.__version__}')
print(f'CUDA available: {torch.cuda.is_available()}')

model_id = 'standardmodelbio/smb-v1-1.7b'
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    trust_remote_code=True,
    device_map='auto'
)

print('smb-v1-1.7b loaded successfully!')
"
```
