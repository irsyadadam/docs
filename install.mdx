  <div className="smb-code-wrap">
    <div className="smb-code-label">bash</div>

  <p className="smb-p">
    1. Clone the <a href="https://github.com/standardmodelbio/quickstart">quickstart repo</a> with <code>demo.py</code> and all dependencies.<br/>
    2. Install <a href="https://docs.astral.sh/uv/">uv</a> if not already present.<br/>
    3. Run <code>uv sync</code> to install the exact locked dependency set (PyTorch, transformers, <code>smb_utils</code>, etc.).
  </p>

  <div className="smb-callout smb-callout-info">
    GPU support is strongly recommended. <code>smb-v1-1.7b</code> has 1.7B parameters and requires approximately 16GB GPU memory for inference.
  </div>

  {/* ==================== MANUAL INSTALLATION ==================== */}

  <h2 id="manual-installation" className="smb-h2">Manual Installation</h2>

  <div className="smb-callout smb-callout-note">
    <strong>Requirements:</strong> Python 3.11+, Git, and <a href="https://docs.astral.sh/uv/">uv</a>.<br/><br/>
    The quickstart uses <a href="https://docs.astral.sh/uv/">uv</a> for dependency management. If you prefer a different tool (conda, pip, etc.), refer to <code>pyproject.toml</code> in the <a href="https://github.com/standardmodelbio/quickstart">quickstart repo</a> for the list of dependencies.
  </div>

  <ol className="smb-steps">
    <li className="smb-step">
      <div className="smb-step-title">Install uv</div>
      <div className="smb-step-desc">
        <div className="smb-code-wrap">
          <div className="smb-code-label">bash</div>
          <pre className="smb-code-block"><code>{`curl -LsSf https://astral.sh/uv/install.sh | sh`}</code></pre>
        </div>
      </div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Clone and install</div>
      <div className="smb-step-desc">
        <div className="smb-code-wrap">
          <div className="smb-code-label">bash</div>
          <pre className="smb-code-block"><code>{`git clone https://github.com/standardmodelbio/quickstart.git
cd quickstart
uv sync`}</code></pre>
        </div>
        <p className="smb-p" style={{marginTop: '12px'}}>
          All dependencies (PyTorch, transformers, <code>smb_utils</code>, etc.) are installed from the lockfile, ensuring a reproducible environment.
        </p>
      </div>
    </li>
    <li className="smb-step">
      <div className="smb-step-title">Run the demo</div>
      <div className="smb-step-desc">
        <div className="smb-code-wrap">
          <div className="smb-code-label">bash</div>
          <pre className="smb-code-block"><code>{`cd quickstart
uv run python demo.py`}</code></pre>
        </div>
      </div>
    </li>
  </ol>

  <div className="smb-code-wrap">

    <pre className="smb-code-block"><code>{`uv run python -c "
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

# Check PyTorch and CUDA
print(f'PyTorch version: {torch.__version__}')
print(f'CUDA available: {torch.cuda.is_available()}')

# Load smb-v1-1.7b
model_id = 'standardmodelbio/smb-v1-1.7b'
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    trust_remote_code=True,
    device_map='auto'
)

print('smb-v1-1.7b loaded successfully!')
"`}</code></pre>
