We provide [`quickstart-pipeline.py`](https://raw.githubusercontent.com/standardmodelbio/quickstart/main/quickstart-pipeline.py) demonstrating an end-to-end workflow using the Standard Model to go from raw data to clinical insight. It performs three key steps:

1. **Simulate Raw Data:** Generates a synthetic [MEDS (Medical Event Data Standard)](https://github.com/Medical-Event-Data-Standard/meds) cohort with distinct clinical phenotypes (Lung Cancer vs. Pneumonia), including longitudinal codes, labs, and medications.
2. **Extract Universal Representations:** Ingests the raw timelines into the Standard Model to produce high-dimensional patient-level embeddings that capture the full causal history.
3. **Train Clinical Predictors:** Uses these frozen embeddings to power downstream tasks including Readmission Risk, Disease Phenotyping, and Survival Analysis.

Don't forget to activate your virtual environment!

```bash
source standard_model/bin/activate
```

Pull the script from GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/standardmodelbio/quickstart/main/quickstart-pipeline.py -o quickstart-pipeline.py
```
